# CareerGhana Data Analyst Internship Tasks

This repository contains all five tasks I completed during the CareerGhana Data Analyst Internship.

## Task 1 - Fitness Tracker Insights Dashboard

This project analyzes daily fitness activity data, including steps, sleep, and calorie information.

Key areas covered:
- Weekly activity trends
- Most active users
- Activity monitoring
- Fitness insights dashboard

The dashboard helps identify user activity patterns and overall wellness trends.

## Task 2 - Sales Performance Auto-Report

This project automates weekly sales reporting using Google Apps Script.

The solution:
- Reads sales data from a CSV file
- Calculates the top 5 products by revenue
- Calculates revenue by region
- Calculates week-over-week percentage change
- Sends a formatted sales report by email

## Task 3 - Customer Churn Predictor

This project identifies customers who may be at risk of leaving.

Two main churn signals were used:
- Customers inactive for 30 days or more
- Customers whose order frequency dropped by 50% or more

Customers are ranked according to their churn risk level so that the highest-risk customers can be prioritized.

## Task 4 - Budget Threshold Alert Tool

This project is an automated budget monitoring system built with Google Sheets and Google Apps Script.

The system:
- Reads expense data by category
- Compares actual spending with allocated budgets
- Detects overspending
- Sends an automatic email alert when a category exceeds its budget

## Task 5 - Employee Productivity Snapshot

This project analyzes employee productivity using Microsoft Excel.

The analysis includes:
- Tasks completed per employee per week
- Average task completion time
- Employee performance ranking
- Weekly productivity findings

## Tools Used

- Microsoft Excel
- Power BI
- Python
- Pandas
- Google Sheets
- Google Apps Script
